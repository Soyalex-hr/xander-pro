🌐 Copia de Seguridad y Uso en la Nube

Esta aplicación está diseñada para funcionar 100% en la web sin bases de datos complejas ni costos mensuales:

  1. Puedes instalarla como aplicación independiente en tu computador o celular haciendo clic en 📲 Instalar App.
  2. Puedes publicarla en tu propio dominio o servidor web simplemente cargando los archivos del proyecto.
  3. Tus datos de empresa, clientes, productos, recetas y cotizaciones se guardan de forma privada en tu navegador y puedes exportar/importar respaldos completos en JSON cuando lo requieras.
